>What it is

A static site, drawn in code.

My portfolio is plain HTML, CSS and JavaScript hosted on GitHub Pages. The pixel crew, ship and Log Pose are drawn on canvas, so there are no image files to manage.

AI tool

Claude (claude.ai) for planning, building and restyling.

Hosting

GitHub Pages, repo tcss490-artifacts.

Stack

HTML, CSS, vanilla JS, canvas pixel art.

>Build log

Seven entries. One site.

Entry 1: Planning

Pasted the assignment and asked what Claude could do. Replied "BUILD IT" without personal details, so the first version used placeholders.

Entry 2: First build

Got a single-file index.html with 4 switchable themes and 5 artifact cards. Then sent my details and ideas for Artifacts 2 to 5.

Entry 4: Restyle

Asked for Framer-style motion, then a dark tech landing page: typing text, count-up stats, scroll reveals and spotlight cards.

Entry 5: Dark purple + fast light

Black and violet theme with a glowing vertical light beam, a counting "5x" headline and a glowing isometric chip.

Entry 6: Darker, light travels the page

Pure black background and a canvas light engine that races up and down with scrolling, plus click pulses and magnetic buttons.

Entry 7: One Piece restyle

Switched to a One Piece look: Wanted-poster cards with a character per artifact, a pixel-art Thousand Sunny with the whole crew, waves, and a pixel Log Pose. Added one page per artifact.

>Reflection

What I learned.

Which AI: Claude (claude.ai).

What worked: Screenshots and clear references.

What didn't: Vague requests, like the ship not being pixelated at first.

What I learned: Be specific and check every change.
